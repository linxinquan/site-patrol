标签浅底通则（Tint = 原色 5%）

全站所有标签（分区标签、分类标签、状态胶囊、角色徽标、置信度标签、进度百分比标签、已校验/已下载等）浅底一律 = 标签自身文字色的 5% 透明度（color.withValues(alpha: 0.05)，令牌 brandTint / successTint / warningTint / dangerTint / yellowTint）。
唯一例外：灰标签（缺陷类型、#自定义标签、楼栋楼层、板块副标题）仍用 surface2 #F4F6F7 实色底。
不适用：实色底白字标签（待整改 / 整改中）、图标块面底（用 Soft 档）。

缺陷严重度（红 / 橙 / 黄 / 绿 四色分级）

用于缺陷标签流与筛选。文字用直白等级词：严重（红）=重要且紧急（重大隐患，局部停工立即上报）；较重（橙）=重要不紧急（限期整改）；一般（黄）=紧急不重要（即查即改）；轻微（绿）=不重要不紧急（常规观察）。浅色底 = 四色原色，透明度 5%。

4. 阴影与层级

全部卡片扁平化：elevationRaised / elevationOverlay / elevationNone 均已置空（const []）。层级仅通过背景色差（白卡 vs 浅灰页面）与选中态浅蓝底表达，不使用投影。

6. 组件规范

AppCard（首页统一卡片）
所有首页板块的视觉基底。
  • 白底 surface · 圆角 radiusLg(12) · 无描边 · 无投影
  • 默认 padding = space4(16)；紧凑卡用 space3(12)
  • 数据闭环价值条、待办卡、项目进度卡均复用此风格
BottomNav（底部 Tab 栏）
纯白底 surface，无顶部描边 / 分割线。
  • 未选中：图标蓝色 #0395FF；选中：文字黑色（非蓝色）
  • iOS 标准高度 49pt（不含 home indicator 安全区）
里程碑卡 _MilestoneChip
横向可滑动，外层列表容器高 60px。
  • 卡高 60 · 底 #F8F8F8（非选中）/ #E6F5FF（选中）· 圆角 8 · padding all(8)
  • 竖排状态标签 20×44 · 圆角 4 · 12/400 竖排
  • 三态（已统一为规范分区色）：当前 = 蓝#0395FF 底白字；完成 = 白底绿#34C759 字；未来 = 白底红#FF3B30 字
  • 选中态：#E6F5FF 底 + 1px #0395FF 边框
  • 日期 12/700/#202224（组件级固定，沿用 Frame 0648）；阶段名 14/400/#60656B
待办卡 _TodoCard
AppCard · padding 12 · 白底圆角 12。
  • 行1：标题 16/700/#202224 + 分类标签（主色 5% 底 / #0395FF 字） ｜ 状态标签（实色底白字圆角6：待整改 #FF3B30 / 整改中 #FF9500）
  • 行2 标签流：严重度 / 类型 / 楼层 / #自定义标签，12/400，圆角 6（严重/较重/一般/轻微按四色分区 + 5% 浅底）
  • 行3：左侧（记录人 + 责任人）为一组 ｜ 右侧时间 12/#919499，spaceBetween 两端对齐
  • 板块间距：数据闭环价值条 → 待办 = 24

114×110 渐变大卡 · 圆角 12。
  • 竖向渐变底 + 36×36 图标 + 标题 14/700 白字 + 副标题 12/400 白字(0.7 透明)
AppButton（主操作按钮）
主操作 = 蓝底白字（accent 系），由 accentHover/Active/Soft 传导状态。
  • 圆角统一 12（radiusButton）· 三形态：filled 实色 / outlined 描边 / text 文字，圆角一致
  • 三档高度为严格值：lg 48 / md 36（默认）/ sm 32；左右 padding lg 24、md·sm 12，上下无 padding（文字在固定高度内垂直居中）
  • 字号 lg 16 / md 14 / sm 12，字重 700，行高 = 字号 + 8，字距 0
  • 实现要点：min/maximumSize 锁高 + tapTargetSize: shrinkWrap——否则 Material 默认 48 点击区会把 md/sm 撑到 48、上下 padding 会把 lg 撑到 56
  • 全局 FilledButton / OutlinedButton / TextButton 主题同步为圆角 12、默认中档 36 高，直写按钮自动继承
  • 纯文字，不带图标：大按钮统一为文字按钮，已移除 icon 参数，禁止「图标 + 文字」组合；全局图标 + 文字按钮改纯文字（巡场主操作、拍照「保存验收记录」、图纸查看器「拍照记录」、巡场子操作、图纸 / 蓝图工具条、拍照控制按钮）
大按钮（全宽 CTA）
登录「开始使用」、引导「下一步 / 开始使用」、巡场主操作、拍照页「保存验收记录」、价值页「开始使用」——均为纯文字不带图标全宽 CTA。
  • 全宽 · 高 48（buttonH_lg）· 圆角 12（radiusButton）· 实色品牌蓝底白字 16/700
  • 禁用态底色 surface3
  • 纯文字不带图标：CTA 仅文字，不配图标

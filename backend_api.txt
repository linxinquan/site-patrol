任务结果。

2.11. 获取任务执行结果数据
描述
1、第三方系统可以主动向浩辰云图服务请求任务的执行状态
2、根据任务请求唯一id查询任务，并返回任务执行，如果已执行完毕，将执行结果返
回，否则仅返回对应的返回码即可
API 地址
${华为云API网关域名}/openapi/v1/getTaskStatus
这里的“华为云API网关域名”固定使用
https://gstarcadsdk.apistore.huaweicloud.com

===== PAGE 26 =====
调用方法
POST
请求参数
requestId=xxx
返回值
status code为200表示请求已经成功对接云服务，rtnCode=0000000表示获取数据成
功，返回下面的信息；其余值表示失败。
成功返回示例
{
"rtnCode": "0000000",
"msg": "success",
"ts": 1677630741619,
"bizData": {
"taskType": "GET_DWG_INFO",

"status": 2,
"resultCode": 0,
"resultMsg": "OK",
"transformStartTime": "2023-03-08 15:17:37",
"transformEndTime": "2023-03-08 15:18:03",
...
}
}
其中status取值为
取值 说明
0 未开始
1 执行中
2 已完成
其中resultCode取值为：0为成功，其他为失败。

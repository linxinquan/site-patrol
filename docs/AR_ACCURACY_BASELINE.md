# AR 量尺精度基线实测 SOP（P1）

> 目的：拿到**我方**（iPhone 14 Pro Max + 本 App + 现场工况）的真实精度底数，
> 据此给清单项定「可判定 / 仅参考」两档——别人的论文数据只是参考，这张表才是门槛依据。

## 1. 器材
- 被测机：iPhone 14 Pro Max（LiDAR）
- 真值：钢卷尺（±1mm）或激光测距仪（±1.5~2mm，更稳）
- 已知长度（尺度校正）：A4 长边 297mm / 瓷砖 600mm / 86 面板 86×86mm
- 记录：本表（Excel/纸质均可），每组 3 次

## 2. 准备
1. AR 页 → 设置 → 「真机自检」确认 LiDAR=支持、会话=运行
2. 先做**尺度校正**（对已知长度重复测 3 次），记 k 值
3. 照度 ≥50 lux，手持稳，围绕目标先走 1~2m 建好追踪

## 5. 判定阈值算法（产出"我方精度表"）

对每个档位（距离×材质）：
- **平均绝对误差** ≤ 该档容差/3 → 标 **可判定**
- 平均绝对误差 > 容差/3 或 离散 >30mm → 标 **仅参考（需卷尺复核）**

容差沿用项目口径：默认 `15mm / 2%`（可在 AR 设置里配置）。

## 6. 判定落到 App
- 「可判定」档：清单/报告给合格/超差结论
- 「仅参考」档：强制显示"重复性 ±x mm（未含系统偏差）· 需卷尺复核"
- 更新 `CONTEXT.md` 的"关键约定"与本 SOP 的实测表

## 7. 边界提醒
- 玻璃/镜面/深色面必然失效 → 标"不可用"，走照片量尺降级
- 任何档位都覆盖不了 4mm 级（垂直度/平整度/阴阳角）——这是物理上限，不在本 SOP 范围

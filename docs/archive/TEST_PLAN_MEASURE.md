## 1. P0-1 标定 2D 修复验证【必测，最关键】

| # | 测试 | 操作 | 通过标准 |
|---|---|---|---|
| 1.1 | 竖线标定（修复前会爆表） | 照片里竖着放卷尺：标定两点选卷尺 0→1000mm（两点几乎同X、不同Y）→ 点"标定" | Chip 显示 mm/px 为合理值；量同方向线段误差 <5%；**不出现天文数字** |
| 1.2 | 斜线标定 | 参照物两端沿对角线放置（如A4纸对角297×210的边斜放），标定后量同平面另一斜距 | 误差 <5% |
| 1.3 | 两点过近防护 | 标定两点几乎重合（<几像素）→ 点"标定" | 弹出"参考物两点过近"提示，不崩溃 |
| 1.4 | 旧数据兼容 | 用 `_test_measure.ps1` 的旧格式 JSON（pixA/pixB）写入后打开会话 | 会话正常读出，mm/px = refMm/|pixB-pixA|（水平退化行为） |

> 1.1 是本次测试的第一优先级：修不好它，量尺数值就是错的，其余全白测。

## 4. 全流程端到端【必测，最后做】

按演示顺序完整走一遍：
选图纸（已校准）→ 图纸点两点量出图纸尺寸 → 拍/选照片 → 标定参照物 → 照片点两点量实测 → 加入校对 → 清单显示（图纸mm/实测mm/偏差/判定）→ 保存 → **重进页面**确认会话恢复。

| # | 断言 | 通过标准 |
|---|---|---|
| 4.1 | 数值合理 | 量已知尺寸（如A4纸宽210mm）：实测 210±10mm |
| 4.2 | 判定正确 | 构造两种场景：①偏差小于容差→绿勾"合格"；②手填图纸尺寸使偏差超容差→红"超差" |
| 4.3 | 会话恢复 | 重进页面：容差、标定、清单完整恢复 |
| 4.4 | 删除项 | 删除一条清单项 → 本地存储同步删除 |

## 5. 精度抽测（有真实墙面才做）【可跳】

卷尺实测 1m / 3m 两段墙面，各拍照测量 3 次：

| 距离 | 目标误差 | 记录 |
|---|---|---|

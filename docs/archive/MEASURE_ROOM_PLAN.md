# 装修量房 · 户型记录量尺（产品+技术方案）

> 需求还原（本次提出）：AR量尺要 **①精准度更高 ②符合工程习惯 ③参考室内装修量尺 ④适配装修 ⑤能记录户型并在图上标注好尺寸**。
> 定位判断：从"点对点测距"升级为 **"量房成图"**——沿墙扫/点一圈 → 自动生成标注尺寸的户型图 → 保存为量房记录（可进报告/对比图纸）。
> 出处参考：[Apple RoomPlan（官方，LiDAR 扫描自动成户型）](https://developer.apple.com/cn/augmented-reality/roomplan/)、[平面圖設計 3D & LiDAR 掃描（消费App案例）](https://apps.apple.com/us/app/%E5%B9%B3%E9%9D%A2%E5%9C%96%E8%A8%AD%E8%A8%88-3d-lidar%E6%8E%83%E6%8F%8F/id6475383389?l=zh-Hant-TW#1)、[如视·庞加莱智慧量房（贝壳系行业方案）](https://www.realsee.com/article/g6o8kyxq?utm_source=website&utm_medium=social_organic&utm_campaign=CO_galois-kolvideo)、[知户型类"边量边画"App](https://www.diyiyou.com/soft/14476.html#1)

## 一、目标产品定义

**「量房模式」**：打开手机对房间 → 用 LiDAR 扫描/定点 → 系统自动生成**户型多边形（墙段）+ 尺寸标注** → 设计师在图上补门窗型号/墙厚/完成面/净高等 → 保存为"量房记录" → 可与施工图对照、进报告。

一句话卖点：**"举着手机走一圈，户型图带尺寸就出来了，还能对照施工图查偏差。"**

## 二、两条技术路线

| | 路线A：RoomPlan 官方扫描（推荐主力） | 路线B：自研 LiDAR 定点成图 |
|---|---|---|
| 原理 | ARKit RoomPlan API：LiDAR 扫一圈自动识别墙/门/窗/房间，输出 USDZ+JSON（墙段、洞口、房间、尺寸） | 复用现有 AR 量尺：手动点墙角→线段→正交吸附→闭合→成图 |
| 精度 | 官方优化，厘米级（短距离更佳） | 取决于打点质量，需自研误差校正 |
| 工作量 | 小（官方框架），但**深度二次开发受限** | 大，可控性强 |
| 成图 | 自动出房间/墙体/洞口 | 手动定点，半自动 |
| 上手 | 需"拿手机绕房间扫一圈"教学 | 指哪打哪，工程习惯可控 |
| 适配 | iOS 16+ 且 **仅 LiDAR 机型**（iPhone 12 Pro+ / iPad Pro 2020+） | 同左 |
| 国内生态 | RoomPlan 仅 iOS；安卓无官方替代 | 安卓可退化为照片/手动量房 |

**推荐：路线A 为主（v1 快速成图），路线B 作为"补点/修正"模式叠加**——RoomPlan 出骨架，设计师手动补工程信息（正是装修量房行业流程：机器给骨架、人工给细节）。

## 三、工程习惯（差异化功能清单，写进 v1）

1. **标注规范**：净尺寸为主、可选轴/完成面；标注线样式对齐图纸习惯（如 900/4200 加圈或箭头），数字单位 mm
2. **正交修正**：>85°<95° 墙角吸附为直角；明显斜墙保留并提示"非直角，请复核"
3. **闭合与闭合差**：首尾自动闭合；周长闭合差 >15mm 提示"存在误差，请复核 X 段"（对应量房行业允许误差口径）
4. **洞口打断**：门窗在墙段上自动打断并标注（门宽900、窗宽+窗台高由 RoomPlan 或手动补）
5. **面积自动**：房间面积自动计算（㎡，保留两位），标注在图中心或列表
6. **净高/标高**：可录入/扫描层高，图侧注标高
7. **成图留痕**：量房记录=照片证据+图+尺寸表，可进报告/与 CAD 施工图对照超差（对接现有量尺校对逻辑：RoomPlan 尺寸 vs 图纸尺寸偏差判定）

## 四、功能流程（v1 草案）

```
入口「量房」→ 选项目/房间
→ ①扫描：RoomPlan 绕房间扫描（提示语：沿墙走一圈，角角落落都扫到）
→ ②确认骨架：墙段/洞口/房间预览，可增删墙段、手动补点（路线B修正）
→ ③标注/补信息：门窗型号、墙厚/材质、净高、完成面（手动表单）
→ ④校验：闭合差/正交提示、与已有图纸对照（若有）→ 判定
→ ⑤保存：量房记录（照片+户型图PNG/SVG+尺寸表JSON）→ 列表/报告
```

## 五、精度与诚实边界（对外口径）

1. **精度声明**：LiDAR 量房为厘米级（约 ±1~2cm@5m 内，RoomPlan 官方优化）；**工程复核仍建议卷尺/激光测距仪对关键尺寸抽测**（行业惯例：机器给骨架、人工精测复核）
2. "高精度+符合工程习惯"= 技术（LiDAR/官方框架）+流程（正交/闭合差/标注规范）双保险，**不是承诺替代验收测量**
3. 装修量房细分：完成面尺寸为主，需设计师补"做法/厚度"——v1 用标注层解决，不做自动识别材质

## 六、与现有 App 的集成点

- 复用：现有 AR LiDAR 原生（`ArMeasureView.swift`）的会话管理/权限；`MeasureSession/MeasureItem` 数据模型扩展（source 加 `'roomplan'`）；报告生成器加"量房记录"章节；校准/图纸对照逻辑
- 新增模型：`RoomPlanRecord {id, projectKey, name, scannedAt, walls[{a,b,lengthMm,openings[]}], rooms[{name,areaM2}], dims[], status, rawJson?}`（兼容默认）
- iOS 原生新增：`RoomCaptureController`（RoomPlan `RoomCaptureSession` 包装，MethodChannel 暴露：start/stop/export→JSON+USDZ）

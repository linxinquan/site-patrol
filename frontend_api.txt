
===== PAGE 1 =====
安装
静态页面引用
script标签引入即可
html
<script src="GStarSDK.js"></script>
单页面webpack开发引用(vue为例)
1. 首先设置webpack.externals,配置GStarSDK不从 bundle 中引用依赖
使用webpack如下配置
js
module.exports = {
...
output: {
...
},
externals : {
'GStarSDK': 'GStarSDK',
}
...
}
使用vue-cli，如下配置：vue.config.js中
js
module.exports = {
configureWebpack: config => {
config.externals = {
'GStarSDK': 'GStarSDK',
}
},
}

===== PAGE 2 =====
2. 单页面入口HTML文件中,srcpit标签引入GStarSDK
html
<script src="./GStarSDK.js"></script>
3. 需使用GStarSDK的vue单文件中,进行引用
js
import GStarSDK from 'GStarSDK'
使用
1. 创建容器标签，作为SDK容器
html
<div id="GStarSDK-container"></div>
2. 实例化SDK
js
const gstarSDK = new GStarSDK({
wrapId: 'GStarSDK-container', // SDK容器ID
switchLayoutCB: switchLayout, // 切换布局回调函数
})
3. 实例调用render方法渲染图纸
js
// ocfData 为图纸数据的buffer
// fileId 为图纸对应的fileId，部分功能需要
gstarSDK.render('ocf', ocfData, fileId)

API
constructor(实例化)
参数
参数 类型 必填 默认值 说明
wrapId String 是 无 SDK容器的DOM ID（容器需要设置宽和高）
mode String 否 'default' 绘图模式，"default":默认值，文字不填充，需要填充元素正常填充；"line":所有元素不填充；"fill":所有需要填充元素都填充
apiHost String 否 无 SDK配套远程API的域名,未配置将无法正常使用“另存为”“另存PDF”“打印”功能
mobileSizeLimit Number 否 5242880 移动端可打开图纸数据的最大限制（字节数），默认5242880(5M)
pcSizeLimit Number 否 12582912 PC端可打开图纸数据的最大限制（字节数），默认12582912(12M)
language String 否 'zh' SDK显示语言设置,类型string，值可选'zh'（简中）/'zh-hk'（繁中）/'en'(英语)/'ko'(韩语),默认'zh'
hideToolbar Boolean 否 false 是否隐藏整个工具栏
toolbarHideItems Object 否 {} 设置需要隐藏的菜单项: 可隐藏的菜单结构

初始化图纸的书签列表
1. 从数据源获取当前图纸的书签数据
2. 图纸 render 完后(由于render是异步方法返回Promise对象，需要在.then回调或者使用async await等待render完后)，给属性 marks.list 赋值传入书签列表数据,完后打开书签面
板即可显示初始化的书签列表进行操作
js
// async 函数中
await gstarSDK.render('ocf', layoutOcf, fileId)
// 获取的图纸书签数据，如果是所有布局书签都在一起存储--
// 则拿当前布局信息从中格式化出当前布局的书签列表，赋予 `gstarSDK.marks.list`
const currentLayoutInfo = gstarSDK.layoutInfo
// 格式化当前布局的书签列表 markList 如上 书签数据格式 所述
gstarSDK.marks.list = markList
书签变动后，通过书签变动回调处理
书签变动（新增、编辑、删除）后，会回调 constructor 时传入的 marksChangeCB 方法传递书签变动的操作类型及变动书签对象,上层可根据相应变动进行书签数据的处理、存储等
也可使用 marks.list 获取当前布局全量最新的书签列表数据，进行处理
切换布局时，书签处理
切换布局时，完成新布局 render 后(由于render是异步方法返回Promise对象，需要在.then回调或者使用async await等待render完后),调用API marks.clear 清除之前的书签数据,再
给属性 marks.list 赋值传入当前布局的书签列表数据以在新布局中显示书签列表
js
async function switchLayout() { // 布局切换回调函数
... 获取新布局图纸数据 layoutOcf
... 获取新布局书签数据 markList
await gstarSDK.render('ocf', layoutOcf, fileId) // 渲染新布局
gstarSDK.marks.clear() // 清除上个布局的书签
gstarSDK.marks.list = markList // 重新传入当前布局的书签列表
}

批注联调逻辑
获取批注，并显示
1. 从服务端获取当前图纸的批注数据
2. 适配含有附件的批注（图片，音频），下面详解原因规则
3. 图纸 render 完后(由于render是异步方法返回Promise对象，需要在.then回调或者使用async await等待render完后)，调用API notes.show 传入格式化后的批注数据对象
批注变动后，通过批注变动回调处理
用户操作（新增、编辑、删除）批注后，会回调 constructor 时传入的 notesChangeCB 方法传递批注变动的操作类型及变动批注对象,上层可根据相应变动进行批注数据的处理、存
储等
也可使用 notes.data 获取全量最新的批注数据，进行处理
切换布局时，批注处理
切换布局时，完成新布局 render 后(由于render是异步方法返回Promise对象，需要在.then回调或者使用async await等待render完后),调用API notes.clear 清除之前的批注显示,再
次调用API notes.show 传入最新的批注数据对象以在新布局中显示最新批注信息
js
async function switchLayout() { // 布局切换回调函数
... 获取新布局图纸数据 layoutOcf
... 获取新布局的批注 currentNotes
await gstarSDK.render('ocf', layoutOcf, fileId) // 渲染新布局
gstarSDK.notes.clear() // 清除上个布局显示的批注与数据
gstarSDK.notes.show(currentNotes) // 重新显示最新的批注数据
}
批注数据的适配
原因说明：
本SDK的批注格式基本与之前协议批注数据格式一样，但是由于浏览器限制不能读取本地磁盘文件的原因，图片批注和音频批注的附件文件不能获取到，需要上层将这两种批注数据做

适配规则：
传入SDK批注数据

添加 data 的位置，参考批注数据对象
图片
给相应图片批注位置添加 data 属性，上层根据之前批注相关协议拿到图片，进行base64编码，给到 data 属性
音频
给相应音频批注位置添加 data 属性，上层根据之前批注相关协议拿到音频，转为MP3个的 arraybuffer ，给到 data 属性
从SDK获取批注数据

端，并补全相应批注附件的 附件大小、路径 等附件参数，从而保持多端同步兼容

事事件件名名 说说明明 ccaallllbbaacckk形形参参
switchLayout 布局切换事件 Object: { nickName: 即将切换的布局显示名, globalName: 即将切换的布局全局标志名 }
ocfSizeOverLimit ocf大小超上限事件 Object: { ocfSize: ocf字节数, limitSize: 当前限制最大字节数 }
noteChange 批注数据变动事件 Object: { action: 批注新增、删除或修改, data: 变动的批注数据 }
functionTrigger 功能触发事件 String: 功能名
markChange 书签变动事件 Object: { action: 书签新增、删除或修改, data: 变动的书签数据 }
